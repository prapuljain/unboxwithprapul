THEME RESTORE UPLOAD STEPS

This package keeps the news/blog-only website but restores the old UnboxWithPrapul visual style:
- black hero/header
- orange accent (#ff4500)
- Bebas Neue big headings
- soft cream background
- card hover animations
- hero glow animation
- old-style rounded chips/buttons

Upload steps:
1. Extract this zip.
2. Open the folder named unboxwithprapul_news_old_theme.
3. Upload the files INSIDE this folder to your GitHub repo root.
4. Let GitHub replace existing files.
5. Commit with: Restore old theme for news blog
6. Wait 1-3 minutes and hard refresh the website.

No shopping page is included.
The blog studio remains at studio.html.
