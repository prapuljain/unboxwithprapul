UNBOXWITHPRAPUL READER THEME V2

This version keeps the attractive black + orange + cream theme, but fixes the oversized font problem.
It is now built for two types of visitors:
1. Daily readers who want clean, comfortable articles.
2. Casual visitors who decide to read because the site looks attractive.

WHAT CHANGED
- Smaller, more readable headings.
- Better article reading width and line height.
- Global wording, not India-only wording.
- Studio page can now upload a featured article image.
- Featured images publish to assets/img/uploads/.
- Shopping section is still removed.

UPLOAD STEPS
1. Extract this zip.
2. Open the folder inside the zip.
3. Upload the files inside that folder to your GitHub repo root.
4. Commit message: Reader theme v2 with Studio image upload.
5. Wait for GitHub Pages deployment.
6. Hard refresh your website with Ctrl + F5.

STUDIO IMAGE STEPS
1. Open https://unboxwithprapul.in/studio.html
2. Write title, summary and article body.
3. Choose Upload featured image.
4. Studio will set the image path automatically.
5. Paste your GitHub token.
6. Click Publish to GitHub.

GITHUB TOKEN PERMISSION
Use a fine-grained personal access token.
Repository access: only this repo.
Repository permissions: Contents -> Read and Write.

Do not paste your GitHub token inside any HTML, CSS or JS file.
